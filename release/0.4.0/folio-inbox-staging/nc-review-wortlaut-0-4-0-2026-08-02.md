# „Zwei unabhängige Modelle fremder Familien" präzisieren

`docs/noblecause-release-0.4.0-fuer-leitstand.md` §4 formuliert „zwei unabhängigen Modellen fremder
Familien". Gemeint ist „fremd gegenüber dem Architekten", gelesen wird „fremd gegenüber dem
Gremium". Codex gehört zur OpenAI-Familie, die bereits eine der drei Gremiums-Familien ist.

Im externen Konsistenz-Review zum Release 0.4.0 als unbelegte Aussage beanstandet. Die Formulierung
war beinahe in einen Lebenslauf übernommen worden.

## Definition of Done

- Formulierung im Release-Bericht präzisiert.
- Geprüft, ob dieselbe Formulierung auf noblecause.ai oder in weiteren Dokumenten steht.
