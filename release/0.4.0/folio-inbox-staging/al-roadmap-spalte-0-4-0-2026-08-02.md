# Roadmap-Spalte entspricht nicht mehr der Wirklichkeit

Die Spalte „Was als nächstes kommt" auf `aion-lumen.ch/folio/` listet `v0.2` und `v0.3` als künftig.
Beide sind veröffentlichte Tags; jüngster Tag ist `v0.4.0`. Dieselbe Fehlerklasse wie die
Terminzeile auf noblecause.ai: eine Aussage über die Zukunft, die die Gegenwart überholt hat.

Bewusst **nicht** im Release-Lauf 0.4.0 umgesetzt — die Roadmap neu zu schneiden ist eine
inhaltliche Entscheidung, keine Konsistenzkorrektur.

## Definition of Done

- Entschieden, welche Vorhaben künftig gelten.
- Spalte trägt nur noch Versionen, die laut Repo nicht veröffentlicht sind.
