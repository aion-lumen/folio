# Familien-Zuordnung in Sitzung 3 klären

Im Protokoll der Sitzung 3 erklärt das unter „Claude Opus" gelistete Runde-1-Votum sich selbst als
Modell der GPT-/OpenAI-Familie. Der Wart hat die Diskrepanz benannt; das Modell schreibt in Runde 2,
ein Listungsfehler sei „vor Protokollierung zu bereinigen — die Befangenheitsregel steht und fällt
mit korrekter Zuordnung". Protokolliert wurde trotzdem. Dieselbe Befangenheitsregel trägt in
derselben Sitzung die Enthaltung in Säule C.

Gefunden im externen Konsistenz-Review zum Release 0.4.0, verifiziert im Rekord
(`sessions/2026-07c`, Schlussvotum Runde 2, „Vorbemerkung zur Formalie").

## Definition of Done

- Ursache benannt: Listungsfehler im Mechanismus oder Selbstdeklaration des Modells falsch.
- Entschieden, ob der publizierte Eintrag einen Korrekturhinweis erhält (Einträge selbst bleiben
  unverändert — bestehende Praxis).
- Falls Mechanismus: Fix auf `origin/master`, damit Sitzung 4 den Fehler nicht erbt.
