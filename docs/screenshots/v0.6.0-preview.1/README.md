# Folio 0.6.0 Preview screenshots

The main product tour is the [mail workflow](../mail/README.md). The images below document the newer modules and their setup states.

[Complete Ledger dashboard, 1920 × 1365](ledger-dashboard-complete.jpg) — one image with assets, income/expenses, cash flow, categories and the period slider. Captured from the released build using the same checked synthetic profile. The `mail-registration`, `calendar-setup` and `model-cohort-unavailable` images are diagnostic setup cases, not representative mail-product screenshots.


All data are synthetic. These are captures of the application with isolated local test profiles, not real mailboxes, calendars, applications or bank accounts.

The Ledger screenshots use the same 50-transaction fixture as 28 independently specified native query checks. Own-account transfers are evidenced and excluded from household totals; their fees remain. March–August 2026: income EUR 33,963.00, expenses EUR 15,413.90, rounded to hundreds in the overview. These are deterministic calculation checks, not an LLM accuracy benchmark.
